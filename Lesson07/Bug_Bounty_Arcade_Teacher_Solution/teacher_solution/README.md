# Bug Bounty Arcade - Student Starter

This project is intentionally broken. Your job is to debug it with a careful process instead of random guessing.

## Open the project

1. Unzip the folder.
2. Open Cursor.
3. Choose **File > Open Folder** and select this folder.
4. Open `index.html` in a browser. You can use a simple local server extension or open the file directly.
5. Keep these files visible in Cursor: `index.html`, `styles.css`, and `script.js`.

## Mission

Find and fix five issues. For each issue, record:

- Expected behavior
- Actual behavior
- Steps to reproduce
- Evidence or error message
- One small fix
- Test result

Do not ask AI to rewrite the entire project.
