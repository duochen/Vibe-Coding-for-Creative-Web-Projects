# 五子棋 Gomoku (Five-in-a-Row)

A simple two-player board game built with plain HTML, CSS, and JavaScript.

## What is Gomoku?

Two players take turns placing black and white stones on a 15×15 board. The first player to get **five stones in a row** (horizontal, vertical, or diagonal) wins.

- **Black** moves first.
- **White** moves second.
- Click an empty cell to place your stone.

## How to Run

1. Open this folder in your file explorer or in Cursor.
2. Double-click **`index.html`**, or right-click it and choose **Open with** your web browser (Chrome, Edge, Firefox, etc.).
3. Play with a friend on the same computer!
4. Click **Restart Game** to start over.

No install or server is required — the game runs entirely in your browser.
