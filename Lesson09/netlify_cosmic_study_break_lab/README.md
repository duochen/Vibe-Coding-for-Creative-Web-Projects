# Cosmic Study Break - Netlify Deployment Lab

This package is for Lesson 9: Deployment, Testing, and Demo Preparation.

## Start here
1. Open `student-materials/Student_Practice_Lab.docx` or `.md`.
2. Test the app by opening `deploy-this-folder/index.html`.
3. Deploy the entire `deploy-this-folder` folder with Netlify Drop.

## Package contents
- `deploy-this-folder/`: the complete working web app
- `student-materials/Student_Practice_Lab.docx`: printable student lesson
- `student-materials/Student_Practice_Lab.md`: editable lesson source
- `student-materials/Deployment_Mission_Record.md`: short student record sheet
- `teacher-materials/Teacher_Guide.md`: pacing, management, rubric, and extensions

No GitHub, npm, framework, build command, API key, or command line is required.
