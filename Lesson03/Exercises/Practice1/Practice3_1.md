Create a simple Wikipedia-style web application for beginner students using only HTML, CSS, and JavaScript.

Project Name:
MiniWiki

Goal:
Build a simple website where users can browse short encyclopedia-style articles, search for articles, and click links between articles.

Technology Requirements:
- Use only HTML, CSS, and vanilla JavaScript
- No backend
- No database
- No frameworks
- Store sample article data directly inside JavaScript as an array of objects

Main Features:
1. Homepage
   - Show the title “MiniWiki”
   - Show a short description: “A simple student-built encyclopedia”
   - Show a list of available articles

2. Article Page Area
   - When the user clicks an article title, display the article content on the page
   - Each article should include:
     - Title
     - Short introduction
     - Main content sections
     - Related article links

3. Search Feature
   - Add a search box at the top
   - When the user types a keyword, filter articles by title or content
   - Show matching article titles
   - If no result is found, show “No articles found.”

4. Related Links
   - At the bottom of each article, show related article titles
   - Clicking a related article should open that article

5. Simple Wikipedia Style
   - Use a clean layout similar to Wikipedia
   - Left sidebar with article list
   - Main content area on the right
   - White background
   - Simple fonts
   - Clear headings
   - Blue links
   - Light gray borders

6. Sample Articles
   Create at least 6 sample articles:
   - Artificial Intelligence
   - Web Development
   - JavaScript
   - Robotics
   - Climate Change
   - Space Exploration

7. File Structure
   Create the following files:
   - index.html
   - style.css
   - script.js

8. Code Quality
   - Add comments so beginners can understand the code
   - Use simple variable names
   - Keep the JavaScript easy to read
   - Make the design responsive for laptops and tablets

9. Extra Feature
   Add a “Random Article” button that opens one random article.

10. Final Output
   The app should run by simply opening index.html in a browser.
