# MoodQuest — Cursor UX Practice (Student Version)

MoodQuest recommends a fun mini-adventure based on a student's mood, available time, and preferred location.

## Run the project

1. Open this folder in Cursor.
2. Open `index.html`.
3. Use a Live Server extension, or open the file directly in a browser.
4. Keep the browser and Cursor side by side.

## Important rule

Do not ask Cursor to rebuild the entire project. Make one small, testable improvement at a time.

## Project files

- `index.html`: page structure and wording
- `styles.css`: visual design and responsive layout
- `script.js`: form behavior and recommendations
- `STUDENT_PRACTICE.md`: detailed lesson instructions
- `UX_TEST_NOTES.md`: peer-testing worksheet
- `.cursor/rules/lesson8.mdc`: project rules for Cursor
