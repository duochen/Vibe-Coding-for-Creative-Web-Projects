# MoodQuest — Cursor UX Practice (Teacher Solution)

This folder contains the completed reference solution for Lesson 8. It demonstrates:

- a clear purpose and first action
- descriptive labels and button wording
- accessible validation feedback
- loading, success, and empty states
- a scannable result with next steps
- an easy-to-find reset action
- responsive mobile layout and keyboard focus styles

Run `index.html` with Live Server or open it directly in a browser.

Use the solution as a reference, not as the only acceptable answer. Student implementations may differ as long as they address observed feedback, preserve core behavior, and pass the regression checklist.
